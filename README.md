# Robot Vision Control

A multi-board robotics project for Linux driver development, camera capture,
motor control, diagnostics, and PC-side monitoring.

## Planned board roles

- RK3588: IMX415 camera capture, vision processing, and display.
- i.MX6ULL: Linux driver exercises, diagnostics, and logging.
- STM32F407: motor and encoder control with a local status display.
- STM32F103: auxiliary I/O and test node.
- Host PC: monitoring, control, and log collection.

## Status

Initial repository scaffold; hardware interfaces and software functions remain to be implemented and verified.
